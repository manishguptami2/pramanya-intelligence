# Pramanya Intelligence Website

Marketing site for **Pramanya Intelligence LLP** (`pramanya-intelligence.com`).

This is a **separate repository** from `llmproxyhub-web2`. Product deep-dives live on [llmpolicyhub.com](https://llmpolicyhub.com); this site covers the company, a product summary, and contact details.

## Pages

- `/` — Home (Overview, From India For the World, Artificial Intelligence, Governance for AI, Data Protection)
- `/products` — llmPolicyHub summary
- `/contact` — Founder bios and LLP contact details

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3010](http://localhost:3010).

## Build

```bash
npm run build
npm start
```
